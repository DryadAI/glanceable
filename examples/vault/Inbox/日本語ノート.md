# 円形ディスプレイの可読性

近眼ディスプレイの可読性は行の垂直位置に依存します。弦の幅は極に近づくほど狭くなるため、矩形に折り返す既存のレイアウトエンジンはガラスの約三分の一を無駄にします。

- 🔴 未対応: 辞書ベースの改行
- 🟡 部分的: 文字は保持されるが改行位置が誤っている
- 🟢 対応済: 文字が失われないこと

Mixed script: the term *chord* is 弦, and a 200-character token in any script
still has to break somewhere.

> [!NOTE] 既知の制限
> 空白で分割するため、空白のない文字列は一つの長い単語として扱われます。

数式記号 𝔊 も含む。See [[Chord Solver]].
